# Karro iOS → TestFlight

CI: `.github/workflows/ios.yml` on `macos-latest`. Builds a signed IPA and
uploads it to TestFlight via `fastlane ios beta` (Fastfile in `fastlane/`).

> Why `fastlane/` and not `ios/fastlane/`? `ios/` is gitignored — it is
> regenerated by `one prebuild` on every CI run and on fresh checkouts.
> Anything inside it would be wiped by `prebuild --clean`. Same reason this
> file is not `ios/DEPLOY.md`.

## GitHub secrets (Settings → Secrets and variables → Actions)

| Secret           | Value                                                        |
| ---------------- | ------------------------------------------------------------ |
| `ASC_KEY_ID`     | App Store Connect API key ID (e.g. `AB12CD34EF`)             |
| `ASC_ISSUER_ID`  | Issuer ID shown on the same Integrations page (a UUID)       |
| `ASC_KEY_P8`     | Base64 of the `.p8` file: `base64 -i AuthKey_AB12CD34EF.p8`  |
| `APPLE_TEAM_ID`  | 10-char Team ID: developer.apple.com/account → Membership    |

If any are missing, the workflow's "Verify Apple secrets" step fails fast and
lists which ones.

## Minting the App Store Connect API key (one-time, ~5 min)

1. App Store Connect → **Users and Access → Integrations → App Store Connect API**.
2. **Team Keys → +** — name it e.g. `karro-ci`, role **App Manager**
   (Admin also works; Developer cannot upload builds).
3. Copy the **Key ID** and **Issuer ID**; **download the `.p8`** — it is
   shown/downloadable exactly once.
4. `base64 -i AuthKey_<KEY_ID>.p8 | pbcopy` and store as `ASC_KEY_P8`.

## First-run checklist (one-time)

1. **Paid Apple Developer Program** membership active (team id above).
2. **Create the app record** in App Store Connect — either:
   - manual: App Store Connect → Apps → + → iOS, bundle id `com.sigilco.karro`,
     name `Karro`, SKU `karro`, or
   - from a Mac/checkout with secrets in env: `bundle install && bundle exec fastlane ios register`
     (runs `produce` against the same API key).
   The record **must exist before the first `pilot` upload** — the workflow
   fails at upload otherwise.
3. Add the four secrets above.
4. Actions → **iOS TestFlight → Run workflow** (or push to `main` touching
   native-relevant paths).

## Signing: why automatic + ASC key, not match

`match` requires a private git repo (`MATCH_GIT_URL`) + `MATCH_PASSWORD` and
periodic cert/profile stewardship. We have exactly one app, one lane, and an
ASC API key, so we let xcodebuild manage signing itself:

- archive/export run with `-allowProvisioningUpdates` and
  `-authenticationKeyPath/-ID/-IssuerID` — Xcode creates/fetches the
  distribution certificate and App Store profile through the API key;
- `export_options.teamID` + `DEVELOPMENT_TEAM` come from `APPLE_TEAM_ID`.

Revisit `match` only if certs must be shared across machines/lanes or the
team grows past a single app record.

## Build numbering

`beta` reads `latest_testflight_build_number` and sets
`CFBundleVersion` = latest + 1 (via `increment_build_number_in_plist`).
First upload falls back to `1`. Marketing version (`0.1.0`) comes from
`app.json` at prebuild time.

## Notes / gotchas

- `ios/` in a local checkout may be stale — e.g. the prebuild in this repo
  was generated before `ios.bundleIdentifier` was set, so it still carries
  `com.anonymous.karro`. Delete `ios/`/`android/` and re-run
  `pnpm prebuild:native` whenever `app.json` native config changes.
- `ITSAppUsesNonExemptEncryption=false` is set in `app.json` → prebuild
  writes it into `Info.plist`, so TestFlight doesn't ask the export-
  compliance question per build. Revisit if encryption is ever added.
- Upload uses `skip_waiting_for_build_processing: true` — the build appears
  in TestFlight a few minutes after the workflow goes green.
- Pods are cached by `pnpm-lock.yaml` hash; bump nothing — a lockfile change
  simply misses cache once.
- macOS/Xcode: `macos-latest` tracks GitHub's image; if Expo/RN pins a
  minimum Xcode newer than the image default, add a `setup-xcode` step or
  pin `runs-on: macos-15`/`macos-26` explicitly.
- Local unsigned-archive smoke test on a Mac: `bundle exec fastlane ios archive`.
